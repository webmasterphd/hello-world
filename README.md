# Concierge Test Prep Dashboard Prototype

A dependency-free front-end prototype for the ConciergeTestPrep.ai student dashboard.

## What this demonstrates

- A premium Concierge Level dashboard that leads with the first-attempt pass guarantee.
- A calm student workflow: resume the day, speak with the Concierge, review Ebbinghaus intercepts, and complete a Concierge Desk assignment.
- Tier preview controls for Free, Executive, and Concierge states.
- A clickable 30-day Bootcamp calendar with Learn, R1-R5, and practice exam moments.
- Navy, gold, silver, and glass styling aligned with the Concierge Test Prep hospitality brand.

## Local preview

```bash
npm run serve
```

Then open `http://127.0.0.1:4173/`.

## Checks

```bash
npm run check
```

This runs a JavaScript syntax check without requiring package installation.
